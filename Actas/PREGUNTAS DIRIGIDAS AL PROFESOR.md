## Cuestionario para el profesor

| Tema | Pregunta | Duda que buscamos resolver |
|---|---|---|
| Alcance del proceso | ¿El proceso TO-BE debe limitarse al registro de clientes interesados o también incluir la confirmación de una reserva? | Definir hasta dónde debe llegar la automatización. |
| Formulario de captación | ¿Qué datos mínimos debería solicitar el formulario para captar clientes de pastelería, baños y otros servicios para mascotas? | Identificar la información necesaria para registrar correctamente a los clientes. |
| Validación de datos | ¿El formulario debe incluir validaciones obligatorias, como nombre, teléfono y tipo de servicio solicitado? | Saber qué controles debe tener el formulario. |
| Proceso AS-IS | ¿El diagrama AS-IS debe mostrar solo cómo se reciben las consultas por redes sociales o también el seguimiento de los clientes? | Delimitar el flujo actual que se debe representar. |
| Proceso TO-BE | ¿El proceso automatizado debe mostrar solo el registro de la consulta o también una tarea posterior para que la emprendedora contacte al cliente? | Determinar si se requiere una etapa de seguimiento. |
| Flowable Cloud | ¿Es suficiente presentar el modelo BPMN creado en Flowable Cloud o también se debe demostrar la ejecución de una instancia del proceso? | Aclarar qué demostración técnica se debe realizar. |
| Entrega en GitHub | ¿El archivo BPMN exportado debe acompañarse de capturas de pantalla, un video explicativo o ambos? | Confirmar qué evidencias deben incluirse en el repositorio. |
| Evaluación | ¿Qué aspectos tendrán mayor importancia en la evaluación: el diseño BPMN, el análisis del problema o la demostración del funcionamiento en Flowable? | Priorizar correctamente el trabajo y la presentación. |
| Coordinación y actas | ¿El profesor prefiere que las actas en GitHub reflejen una rotación semanal estricta de roles o evalúa el cumplimiento general de las tareas asignadas? | Aclarar si es obligatorio cambiar los roles semanalmente o si basta con documentar las responsabilidades y el cumplimiento de las tareas de cada integrante. |
